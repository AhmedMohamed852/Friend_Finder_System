💡 الفكرة

Friend Finder هو تطبيق شبكة اجتماعية — فكرته إن كل مستخدم يقدر يتعرف على ناس جديدة بناءً على الاهتمامات المشتركة، يبعت طلبات صداقة، يتكلم في رسائل مباشرة، يعمل منشورات ويشوف فيد أصحابه — كل ده بشكل آمن عن طريق JWT.

JWT Authentication

  • ·كل طلب لازم يجيب Bearer Token
  • ·AuthFilter يورث من OncePerRequestFilter
  • ·يُخزَّن في SecurityContextHolder
  • ·Public فقط: /api/auth/** + Swagger
🔒

تشفير الباسورد

  • ·BCryptPasswordEncoder
  • ·Salted Hash — مش ممكن تعكسه
  • ·مش بتتخزن أبداً بشكل نصي
  • ·طول التخزين 100 حرف
🌐

CORS Config

  • ·Allowed Origin: localhost:4200
  • ·GET · POST · PUT · DELETE · OPTIONS
  • ·Allow Credentials: true
  • ·Stateless Session
👮

Role-Based Access

  • ·@PreAuthorize("hasRole('USER')")
  • ·@EnableMethodSecurity
  • ·أدوار: USER / ADMIN
  • ·يتحقق على مستوى كل Method
